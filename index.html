Subtítulos en directo

JSON del guion (orden cronológico). Formato:
{"title":"OLIVER!","lang":"en-GB","lines":[{"who":"Oliver","text":"Please sir, I want some more","type":"line"}]}
También vale un array simple de líneas. type: line | lyric | dir (las "dir" se muestran pero no se escuchan).
Opcional: "translation" en cada línea para mostrar el subtítulo traducido.
